# UsageNow

**See what’s left. Keep building.**

UsageNow is a native macOS menu bar app for tracking Codex and Claude Code usage, limits, reset times, and token activity.

## Website

[usagenow.com](https://usagenow.com)

## What it does

- Track Codex usage
- Track Claude Code usage
- Monitor 5-hour and weekly limits
- See reset times at a glance
- View token activity in one place
